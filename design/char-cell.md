# 文讀 글자 셀 표시 기준

2026-09-22 현행 기준. [DESIGN.md](../DESIGN.md)의 UI 원칙 중 학습 본문에 적용하는 세부 계약이다. 구현은 [render.ts](../src/render.ts), [reading-align.ts](../src/reading-align.ts), [style.css](../src/style.css), [cell-select.ts](../src/cell-select.ts)를 따른다. 코드 주석에서 참조하는 R1~R9 번호는 유지한다.

## 표시·선택 계약

| 기준 | 유지할 동작 |
| --- | --- |
| R1 | 음 표시 전후 한자의 가로 위치·줄바꿈을 유지한다. 독음 표시 공간은 세로 간격으로 확보한다. |
| R2 | 드릴 밑줄 구간도 글자 단위로 줄바꿈하며 다음 줄로 이어진다. 앞·뒷면이 같은 셀 구조를 사용한다. |
| R3 | 드릴 밑줄은 한자 아래에 고정하고 독음은 그 아래 둔다. 음 토글로 밑줄 위치가 흔들리지 않게 한다. |
| R4 | 복습 화면의 독음은 한자에만 1:1로 정렬하고 공백·문장부호·현토는 음 없이 통과한다. |
| R5 | 정렬할 수 없는 독음은 카드 아래 한 줄로 표시한다. 한자 2자 이상 카드의 정렬 실패는 데이터 lint가 경고한다. |
| R6 | char 카드와 훈+음이 있는 한 글자 카드는 아래 한 줄 독음 표시를 유지한다. char 카드는 뒤집어도 대형 한자가 이동하지 않도록 하단 공간을 확보한다. |
| R7 | 카드 추가용 선택 결과에 독음을 섞지 않는다. 현재는 네이티브 문자열 드래그 대신 글자 셀의 포인터 선택을 사용한다. |
| R8 | 문법 보기·독음·드릴 밑줄을 함께 표시해도 위 배치 기준을 유지한다. |
| R9 | 문법 편집 그리드에도 같은 글자·독음 표현을 사용한다. 편집 그리드의 독음은 일반 표시와 달리 흐름 안에 배치한다. |

복습 표시의 엄격한 독음 정렬과 문장 편집기의 부분 입력은 구분한다. 편집기는 한자별 칸에 미완성 독음을 유지하고, 저장 문자열은 원문의 토·부호를 유지하고 한자마다 독음 또는 빈칸 `·`를 넣는다. 끝 빈칸도 생략하지 않으며 전부 빈칸이면 빈 문자열로 저장한다. 기존 독음의 배치가 모호하면 원본과 선택 안내를 표시한다. 초과 입력은 별도로 유지하고 사용자가 처리하기 전까지 수정한 독음의 저장을 막는다. 아직 입력하지 않은 칸을 곧바로 오류로 처리하지 않는다.

## 변경 시 확인

- 긴 문장 뒤집기와 음 토글: 가로 배치·줄바꿈, 밑줄과 음의 높이.
- 현토·부호가 있는 문장, 독음 부족·초과, 한 글자 카드의 표시.
- 음을 켠 상태의 셀 선택: 카드 추가로 전달되는 원문에 독음이 섞이지 않는지.
- 문법 보기·편집과 독음·드릴 표시가 겹칠 때의 배치.
- 문장 편집기에서 부분 입력·붙여넣기·한글 IME 조합 및 저장 후 복습 표시.

자동 검사는 `test/reading-align.test.ts`, `test/select-gesture.test.ts`와 데이터 lint를 포함한다. 기기별 육안 검증은 [#5](https://github.com/river11456/mundok/issues/5)의 환경·결과 기록으로 판단한다. 과거의 “경고 0건·구현 완료” 기록을 현재 검증 근거로 사용하지 않는다.
